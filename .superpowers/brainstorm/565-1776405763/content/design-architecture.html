设计方案 — 架构与数据流

方案 A：轻量修复，两个核心问题

预设保存改造

当前 buildMergedPreset 只合并 border + infoBar 基础字段，丢失 titleFontSize 等。

buildMergedPreset() → 合并所有 infoBar 字段
  → 弹窗增加类型选择：[仅边框] [完整预设]
  → 保存到 localStorage 时区分 presetType: 'style' | 'full'
  → 应用预设时，根据 presetType 决定是否覆盖 infoBar

边框拖拽修复

当前松手后 setZoom(savedZoom) 触发 applyZoom → 重新计算 layout → 画布跳变。

pointerup → 解锁 canvas CSS → 清除拖拽状态
  → requestAnimationFrame(重绘一次)
  → 不调用 setZoom，canvas 尺寸不变，仅更新 CanvasRenderer 内部像素
