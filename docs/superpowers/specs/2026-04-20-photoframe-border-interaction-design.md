# PhotoFrame 边框交互重构 + 功能升级设计文档

> 日期：2026-04-20
> 状态：设计中

## 1. 概述

将 PhotoFrame 的边框拖拽交互从 HTML overlay 架构重构为 Canvas 内联渲染，消除松手重绘、拖动不实时、内外边框互相干扰等问题。在此基础上增加智能参考线、撤销/重做、文字自由拖拽、快捷键等体验提升。

## 2. 核心架构重构

### 2.1 手柄 Canvas 化

**现状**：手柄是 HTML 元素（`.br-handle`），通过 CSS 定位在 Canvas 上方。拖拽时 HTML 手柄和 Canvas 渲染两套系统需要手动同步。

**新方案**：手柄绘制直接嵌入 Canvas 渲染管线，在 `canvas-renderer.js` 中新增：

```
drawBorderHandles(ctx, layout, dragState)
```

- `ctx`：预览 Canvas 的 2D 上下文
- `layout`：当前布局信息（来自 `getLastLayout()`）
- `dragState`：拖拽状态对象（可选，拖拽期间传入用于绘制虚线预览）

**手柄样式**：
- 外边框手柄：琥珀色实心圆，直径 14px，白色描边 2px
- 内边框手柄：蓝色实心圆，直径 14px，白色描边 2px
- 悬停时：直径增大到 18px，增加光晕效果
- 拖拽中：高亮显示，虚线预览框

**8 个手柄位置**：4 角（tl, tr, bl, br）+ 4 边中点（t, b, l, r）

### 2.2 外边框/内边框完全解耦

**外边框模式（outer）**：
- 只改变 Canvas 输出尺寸（`output.longEdge` 的等效值）
- 图片的渲染位置和像素大小**完全不变**
- border 值相应变化以匹配新的 Canvas 尺寸
- 效果等同于"增加/减少白边宽度"

**内边框模式（inner）**：
- 只改变 `border.*` 值
- Canvas 总尺寸**不变**
- 图片位置随边框变化而移动
- 效果等同于"调整图片在画布中的位置"

**数学关系**（以外边框模式为例）：
```
初始状态: canvasW0 = photoW + left0 + right0
拖拽后:   canvasW1 = canvasW0 + delta
          left1 = left0 + deltaLeft
          right1 = right0 + deltaRight
          photoW 不变, photoX 不变
```

### 2.3 实时渲染

- 拖拽期间使用 `requestAnimationFrame` 每帧重绘，去掉 80ms 节流
- 使用 `previewCanvas` 作为拖拽专用渲染目标
- `pointermove` 只在 `window` 级别监听，移除手柄元素上的重复监听
- `pointerup` 时触发一次完整分辨率重绘

### 2.4 拖拽预览线

拖拽时绘制半透明虚线框：
- 虚线颜色：#FF9500（外边框）/ #007AFF（内边框）
- 线宽 2px，dash 模式 [6, 4]
- 显示变化方向箭头和像素差值标注
- 松手后虚线消失，边框确认到新位置

### 2.5 DOM 清理

移除 `index.html` 中的以下元素：
- `.br-handle`（8 个手柄 DOM 元素）
- `.border-resize-overlay`（overlay 容器）
- 相关的 CSS 样式

### 2.6 影响文件

| 文件 | 变更 |
|------|------|
| `js/canvas-renderer.js` | 新增 `drawBorderHandles()`, `drawDragPreviewLine()` |
| `js/app.js` | 重写 `setupBorderResizeMode()`, 移除 `updateBorderResizeHandles()`, 精简拖拽逻辑 |
| `index.html` | 移除 HTML overlay 手柄 DOM |
| `css/style.css` | 移除 `.br-handle` 相关样式 |

## 3. 智能参考线 + 比例吸附

### 3.1 吸附目标

拖拽边框时自动吸附到以下常用比例（基于 Canvas 宽高比）：

| 比例 | 名称 | 宽高比 |
|------|------|--------|
| 1:1 | 正方形 | 1.000 |
| 4:3 | 标准 | 1.333 |
| 3:2 | 135胶片 | 1.500 |
| 4:5 | Instagram | 0.800 |
| 16:9 | 宽屏 | 1.778 |
| 21:9 | 超宽屏 | 2.333 |
| 2.4:1 | XPan | 2.400 |
| 2:1 | 612 | 2.000 |
| 3:1 | 617 | 3.000 |

### 3.2 吸附行为

- 吸附阈值：手柄距目标比例位置 15px 内
- 吸附时显示比例名称浮层（如 "16:9"）
- 按住 `Alt` 键临时禁用吸附
- 按住 `Shift` 键锁定当前比例等比缩放

### 3.3 快捷比例按钮

在边框面板增加一排按钮：`1:1` `4:3` `3:2` `4:5` `16:9` `2:3` `自定义`

点击后平滑过渡到新比例（使用 `requestAnimationFrame` 动画，200ms）。

### 3.4 影响文件

| 文件 | 变更 |
|------|------|
| `js/app.js` | 新增 `calcSnapRatio()`, `applyAspectRatio()`, 比例按钮事件 |
| `js/canvas-renderer.js` | 新增吸附指示器绘制 |
| `index.html` | 新增比例按钮组 DOM |

## 4. 撤销/重做系统

### 4.1 历史记录结构

```javascript
{
  timestamp: number,
  type: 'border_change' | 'crop_change' | 'text_move' | 'preset_switch',
  before: { /* 状态快照 */ },
  after: { /* 状态快照 */ }
}
```

### 4.2 触发条件

以下操作记录历史：
- 边框拖拽结束（pointerup）
- 边框滑块值变化（debounce 300ms）
- 裁剪区域确认
- 文字位置拖拽结束
- 预设切换
- 比例按钮点击

### 4.3 快捷键

| 快捷键 | 操作 |
|--------|------|
| `Ctrl+Z` / `Cmd+Z` | 撤销 |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | 重做 |
| `Ctrl+Y` / `Cmd+Y` | 重做（备选） |

### 4.4 UI

顶部工具栏新增撤销/重做按钮：
- 撤销按钮：↩ 图标，无历史时灰色禁用
- 重做按钮：↪ 图标，无可重做项时灰色禁用

### 4.5 容量限制

- 最多 50 步历史
- 超出后自动丢弃最早记录
- 每次新操作清空 redo 栈

### 4.6 影响文件

| 文件 | 变更 |
|------|------|
| `js/app.js` | 新增 `UndoManager` 类, 快捷键绑定 |
| `index.html` | 新增撤销/重做按钮 |
| `css/style.css` | 按钮样式 |

## 5. 文字区域增强

### 5.1 自由拖拽

- 进入"文字位置"模式后，在预览 Canvas 上绘制文字区域的选择框
- 用户可以直接拖拽文字到任意位置
- 拖拽期间显示十字参考线辅助对齐

### 5.2 对齐选项

边框面板中文字区域新增：
- 对齐按钮组：左对齐 / 居中 / 右对齐
- 水平偏移滑块：-50% ~ +50%（相对于底部边框区域宽度）
- 垂直偏移滑块：-30% ~ +30%

### 5.3 多行独立拖拽

- 标题、副标题、附加文字各自独立可拖拽
- 每行文字有独立的拖拽手柄
- 手柄位于文字行右侧中点

### 5.4 智能吸附

- 拖拽时自动吸附到水平/垂直中线
- 吸附阈值：8px
- 吸附时显示蓝色对齐线

### 5.5 影响文件

| 文件 | 变更 |
|------|------|
| `js/canvas-renderer.js` | 文字手柄绘制 + 对齐线绘制 |
| `js/app.js` | 文字拖拽事件处理 |

## 6. 其他体验提升

### 6.1 实时预览 FPS 指示器

- 左下角显示当前渲染帧率
- 颜色标识：≥30fps 绿色，15-29fps 黄色，<15fps 红色
- 仅在拖拽/交互期间显示

### 6.2 快捷键支持

| 快捷键 | 操作 |
|--------|------|
| `R` | 旋转画布方向（横竖切换） |
| `F` | 预览适配窗口 |
| `C` | 进入/退出裁剪模式 |
| `B` | 进入/退出边框调整模式 |
| `T` | 进入/退出文字位置模式 |
| `+` / `-` | 缩放预览 |
| `0` | 重置缩放到 100% |

### 6.3 预设搜索

- 预设列表顶部增加搜索输入框
- 支持按名称、分类关键词过滤
- 实时过滤，无需回车

### 6.4 缩放改进

- `Alt+滚轮`：以鼠标位置为中心缩放
- 双指触控板捏合缩放
- 缩放时显示当前缩放百分比浮层

### 6.5 影响文件

| 文件 | 变更 |
|------|------|
| `js/app.js` | 新增快捷键绑定、FPS 计算、预设搜索、缩放逻辑 |
| `index.html` | 搜索框、FPS 指示器 DOM |
| `css/style.css` | 新组件样式 |

## 7. 实施顺序

1. **第一阶段**：核心架构重构（Canvas 手柄 + 实时渲染 + 解耦）
2. **第二阶段**：撤销/重做系统
3. **第三阶段**：智能参考线 + 比例吸附
4. **第四阶段**：文字区域增强
5. **第五阶段**：其他体验提升（快捷键、搜索、FPS、缩放）

每个阶段完成后应可独立运行、无回归。

## 8. 风险与缓解

| 风险 | 缓解 |
|------|------|
| Canvas 手柄点击精度不如 HTML | 增大手柄直径，增加悬停光晕 |
| 历史栈内存占用 | 限制 50 步，只存必要状态差异 |
| 吸附误触发 | 15px 阈值 + Alt 键临时禁用 |
| 大文件实时渲染性能 | 预览保持 1400px，导出才用全分辨率 |
